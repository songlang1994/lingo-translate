# Lingo Translate

macOS 菜单栏翻译工具。在任意应用中选中文字，按快捷键唤起浮动面板，由大模型完成翻译；原文与译文左右对照、按段落对齐。

## 功能

- 全局快捷键唤起浮动面板，默认 `⌥⌘L`；可录制组合键，也可设为双击修饰键
- 唤起时自动读取其他应用的选中文本并开始翻译
- 左侧原文保持原样、可自由编辑，右侧译文流式输出，可随时停止
- 输入单词或词组时，译文下方额外显示音标、词性、释义和例句
- 译文按段落与原文对齐，点击段落时两侧一起高亮
- 原文为空或全选时粘贴会自动开始翻译；手动编辑原文不会打断正在进行的请求
- 支持自动检测源语言、交换语言与两侧内容、复制完整译文
- 面板不激活应用，关闭后焦点回到原来的窗口；菜单栏常驻，不占 Dock
- 原生 Swift + SwiftUI / AppKit，无第三方依赖

## 环境

- macOS 14 或更新版本
- Xcode 16 或更新版本
- 一个 Responses 风格的模型接口，如 OpenAI、DeepSeek

## 构建

```bash
make run      # 构建 Debug 并启动
make test     # 运行单元测试
make release  # 构建 Release 并打包到 dist/
make install  # 构建 Release 并安装到 /Applications
```

也可以用 Xcode 打开 `Lingo.xcodeproj`，运行 `Lingo` scheme。

## 配置

首次启动或配置不完整时，应用会打开设置窗口：

| 项目 | 说明 |
| --- | --- |
| Endpoint | Responses 接口地址，或服务的基础地址，如 `https://api.deepseek.com` |
| Model | 模型名称，如 `gpt-4.1-mini` |
| API key | 接口密钥，保存在系统钥匙串；本地地址可留空 |
| Reasoning effort | 思考级别，默认 `None`；`Default` 由服务端决定 |

Endpoint 可以只填服务地址，应用会自动补全 `/v1/responses`；已经是完整地址时保持不变。

## 使用

| 操作 | 说明 |
| --- | --- |
| 唤起面板 | 全局快捷键，默认 `⌥⌘L` |
| `⌘↩` | 立即翻译 |
| `Esc` | 隐藏面板 |
| `⌘W` / `⌘Q` | 隐藏面板，不退出应用 |
| 粘贴 | 原文为空或全选时，粘贴后自动翻译 |
| 点击段落 | 与对应译文一起高亮，再次点击取消 |
| 语言菜单 | 选择源语言与目标语言，源语言支持自动检测 |
| 交换 | 交换语言和两侧文本；源语言为自动检测时不可用 |
| 复制 | 复制完整译文 |
| 拖动释义栏上沿 | 调整释义窗格高度，下次启动保持 |

单词或词组（单行、最多四个词或十二个汉字）会在译文下方多出一张释义卡片，列出音标、词性、释义和例句；句子、代码和地址不显示卡片。释义请求与翻译同时进行，失败时卡片直接隐藏，不影响译文。释义窗格的高度可以拖动调整并记住，两栏始终保留至少一行原文与译文。

自动读取选中文本和双击修饰键快捷键需要「辅助功能」权限。应用不会在启动时申请，可在设置窗口中打开系统设置授权。

## 说明

- 仅支持 Responses 风格接口，未接入 Chat Completions。
- 未开启 App Sandbox，也未公证；适合本机或开发机使用。
- 交互形式参考 [m-inan/mac-translate](https://github.com/m-inan/mac-translate)。
